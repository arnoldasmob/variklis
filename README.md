# Variklis ir štanga

Hibridinio atleto treniruočių dashboardas. **Šiame repozitorijoje nėra jokių asmeninių
duomenų** — tik puslapio apvalkalas.

Visi skaičiai (Garmin rodmenys, svoris, miegas, HRV, treniruočių žurnalas) guli
privačiame repozitorijoje `variklis-duomenys` ir užkraunami tik su asmeniniu
fine-grained token'u, kuris laikomas naršyklės `localStorage` ir niekada nepatenka
į šitą kodą.
